PROYECTO 01

MAURI / Gana la Fecha

Proyecto freelance de mantenimiento, debugging, builds Android/Web y automatización de despliegues sobre una app Flutter/Firebase.

TipoMantenimiento correctivo y evolutivo
PlataformasAndroid · Web
Stack principalFlutter · Firebase
FocoDebugging · Builds · CI/CD · Despliegues

MAURI / Gana la Fecha fue un proyecto freelance de mantenimiento correctivo y evolutivo sobre una aplicación Flutter/Firebase y su landing web.

En esta sección se documentan incidentes relacionados con debugging, infraestructura, CI/CD, despliegues y validación técnica en un contexto de cliente real.

Mobile / App

  • Flutter
  • Android Build

Backend / Plataforma

  • Firebase
  • Firebase Hosting

CI/CD

  • GitHub Actions
  • GitHub

Control de versión

  • Git
  • MAU-001 — Pipeline Android bloqueado por configuración de build.
  • MAU-002 — Crash crítico durante el inicio de Flutter Web.
  • MAU-003 — Problemas de despliegue y publicación de la versión Web.
  • MAU-004 — Hardening de Firebase Hosting y reglas de seguridad.
Evidencias previstas

GitHub Actions overview · run fallido · run exitoso · artifacts generados · error Flutter Web · validación post-fix

Este proyecto permitió trabajar sobre problemas reales de mantenimiento, despliegue y validación técnica, integrando debugging, revisión de logs, configuración Firebase y automatización de builds.
