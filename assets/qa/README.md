# QA Lab Evidence

Este directorio almacena todas las evidencias visuales utilizadas en el QA Lab del portfolio.

## Organización

Cada proyecto contiene:

- `overview/`
  Capturas generales del proyecto (pantallas principales, vistas generales, etc.).

- `incidents/`
  Evidencias organizadas por incidente.

## Convención de nombres

Cada incidente tendrá su propia carpeta.

Ejemplo:

GLF-001-pipeline-build/

Dentro de cada carpeta las imágenes deberán nombrarse con un prefijo numérico.

Ejemplo:

01-actions-overview.png

02-build-failed-google-services.png

03-build-success-artifacts.png
